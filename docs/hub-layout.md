# HUB — этап 1

HUB создаётся из Roblox Instance API: площадь из чёрного камня, золотая отделка,
портал катакомб, четыре светильника и вывески. Внешняя граница — 94 студии от
центра по X/Z; площадка закрыта низким парапетом. Точка появления — `(0, 4, 51)`,
портал — `(0, 11, -65)`. Центральная дорожка свободна от декора.

`HubBuilder.build(parent)` возвращает `model`, `spawnCFrame`, `portalPrompt`.
Серверный bootstrap подключает обработчик портала; модуль геометрии не принимает
клиентские команды и не запускает телепорты. У портала есть мобильный
ProximityPrompt с удержанием 0,35 секунды и радиусом 14 студий.

Стела, магазин, VIP-зона и вывеска зала славы — явно помеченные заготовки будущих
этапов, без фиктивных рейтингов, покупок или VIP-проверок. В HUB нет внешних
моделей, частиц или теней от дополнительных источников света. Проверка
проходимости и фактической частоты кадров требует запуска в Roblox Studio и на
тестовом телефоне.
