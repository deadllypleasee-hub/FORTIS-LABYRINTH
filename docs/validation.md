## Исправления по результатам проверки

- Проверка портала теперь использует Attachment.WorldPosition, а не локальный Position.
- CorridorGenerator отклоняет диагональные точки, даже если их Manhattan-расстояние равно шагу сетки.
- Смертельный удар завершает выдачу награды до отложенного сигнала Humanoid.Died.
- Ошибка сохранения при переходе обновляет HUD и позволяет повторить действие.
- Повторное освобождение профиля после неоднозначного ответа хранилища не выдаёт награды повторно.
- Повреждённые входные данные валидатора отклоняются без исключения.

## Что эти результаты не подтверждают

Lune не симулирует физику Roblox, Humanoid, Pathfinding, клиентскую репликацию и облачные сервисы. Его Instances не вычисляют Attachment.WorldPosition и не синхронизируют Position/CFrame полностью как движок; тесты статической геометрии учитывают это ограничение. Команды сборки Rojo упаковывают код, но не запускают игровой сервер.

Не выполнены: запуск в Studio, игра на Android, реальные Teleport/DataStore/MemoryStore, проверка R6/R15 в движении, сетевые и нагрузочные испытания, измерения FPS, публикация Experience. Полный перечень — [studio-checklist.md](studio-checklist.md). GitHub Actions выполняет те же доступные автоматические проверки и сохраняет артефакты; статус его запуска проверяется отдельно.
